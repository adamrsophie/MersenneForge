MersenneForge
Status Usage GitHub

Checked primality tests for Mersenne numbers, in Rust.

MersenneForge runs Lucas-Lehmer and base 3 probable prime tests of Mp = 2p − 1 with Gerbicz error checking, PRP proofs, and durable checkpoints.

View on GitHub Capability status

Design

One protocol layer

The LL, PRP, Gerbicz, proof, and checkpoint state machines are written once over a small arithmetic trait. Backends only do modular arithmetic.

Errors caught, not hidden

Gerbicz checks with rollback for PRP, the Jacobi check for LL, hashed and versioned checkpoints, and atomic writes.

Pure Rust

No linked native library and no upstream code. Protocol semantics and the proof format follow PRPLL (gpuowl).

Build and run

cargo build --release                  # cpu and dwt backends
cargo build --release --features gpu   # adds the wgpu backend

mersenne-forge doctor --json --exponent 44497
mersenne-forge run --test prp --exponent 44497 --backend dwt \
    --proof-power 8 --proof-dir work/proof --checkpoint-dir work/ckpt --budget 1h
mersenne-forge verify --proof work/proof/44497-8.proof --backend cpu
mersenne-forge work --worktodo worktodo.txt --results results.json.txt \
    --checkpoint-dir work/ckpt --proof-dir work/proof --backend dwt
mersenne-forge check-factor --exponent 11 --factor 23

Requires Rust 1.89 or newer.
