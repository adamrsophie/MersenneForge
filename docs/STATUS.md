# Capability status

Each capability is marked **done** (implemented and tested on this project's own hosts), **CI tested** (compiled, and its CPU tests passed, on GitHub's Linux runners with Rust 1.100.0 and 1.89; GPU and CUDA code there is only compiled), **written** (code and tests written, compiled in CI at most, but the paths that matter have not run), **partial**, **blocked** (implemented as far as possible without hardware or a tool this project has not had access to), or **not started**. "Tested" names the evidence in [VALIDATION.md](VALIDATION.md). Nothing marked written, blocked, or not started is claimed to work.

Note: the changes after the validation record of 2026-11-19 were written while the build host was too loaded to compile or test, and were then compiled and tested by continuous integration instead (see "Continuous integration (2026-11-24)" in VALIDATION.md). Since run 45489277161 the GPU suites also run there on Mesa llvmpipe, a software Vulkan device; no GPU kernel written since then has run on a hardware GPU, and no CUDA kernel has run at all.
